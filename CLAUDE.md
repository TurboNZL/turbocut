# TurboCut: project handoff

A lightweight, cross-platform multi-track video editor with built-in auto captions. Read `docs/ARCHITECTURE.md` first.

## Engine
Pinned to TurboNZL/turboengine (`.turboengine.json`; `docs/development/ENGINE.md` says what was taken from which module and what differs). The engine is a **reference, not a dependency**: before building something every app would want (updates, release naming, theme picker, settings layout, guides), look in the engine's `modules/` and `themes/docs/INTEGRATION.md` first. A cloud session sees only attached repositories: attach the engine read-only with `add_repo`. If you improve something here that other apps could use, add it to `docs/development/ENGINE_CONTRIBUTIONS.md` so it can be ported back. Read `PROJECT_BRIEF.md` for the long-lived goals and rules.

## Naming
- The product is styled **TurboCut** (capital T, capital C) in everything a person reads: UI, docs, window titles, error messages, comments, commit and PR text.
- Machine identifiers stay lowercase: repo and npm package `turbocut`, file-format tag `turbocut.captionPreset`, CSS/storage prefixes.

## Decisions (don't re-ask)
- One TypeScript web app; Electron for Windows and Ubuntu, Capacitor for Android. No platform-specific app code.
- Themes come from `turbothemes` (TurboNZL/turbothemes), following its `docs/CONTRACT.md`.
- Shorts (9:16, under a minute) are the main case; 16:9 up to about 20 minutes must work. Low friction over detail.
- Time is integer frames. Core is pure and unit tested.
- Captions: presets are importable/exportable JSON; the bounce entrance must match the original `ass_bounce.py` (parity test in `test/captions.test.ts`).
- Transcription runs locally on WebGPU or on a remote GPU server over the LAN; same `Transcriber` interface.
- Twitch import: paste a clip URL; resolver runs outside the page.
- Versions are CalVer Year.Month.Update (`2026.10.3`), stamped by `build.yml`; the in-app updater reads GitHub Releases.
- **No GitHub Pages** (the owner does not want a paid hosting dependency) and no landing page site: the **home screen is in the app** (`src/app/home.ts`: start a project, updates, downloads with APK help, guides). `scripts/serve.mjs` is the self-host server (`--https` for LAN, since WebCodecs needs a secure page), shipped as `turbocut-<version>-web.zip`.
- Letter holes: **filled is the default** and means every hole is solid (not only holes narrower than the outline). Per-letter e2e with the real font in `e2e/run.mjs`; the metric must count enclosed pixels with alpha < 8 (a threshold of 200 counted the anti-aliased edge and hid the bug).
- Fonts: the font manager (`src/app/fontManager.ts`) is the one place to add, preview, default and remove fonts. Layouts: `src/app/layout.ts` (data and validation) and `layoutManager.ts` (Settings → Layout); the applied layout sets `data-panel`, `data-density`, `--panel-w`, `--tl-h` on `#app`. Edit layouts in place (`Object.assign`), the controls hold a reference.
- Guides: user guides are `docs/guides/*.md`, bundled by `src/app/guides.ts`; the renderer (`markdown.ts`) only inserts text. Keep them accurate: they are what the owner reads on the phone.
- UI structure follows the engine: dialog title `h2` in a flex `.bt-titlebar`, panels `section.card.bt-panel` (`panel()` in `dom.ts`), in-page tabs `.tabs`/`.tab` with `role=tab` (never `.bt-tab`), SVG icons not emoji. e2e selects tabs with `getByRole('tab')`.
- Asset names are lowercase (`turbocut-2026.10.5-android.apk`).
- Caption styles: the built-in preset is generated from settings and read-only; user presets can bundle fonts (base64 `fonts` in the JSON, limits in `parsePresetFile`). Never commit font files (the e2e test font is generated by `make-media.sh`).

## Commands
`pnpm install --ignore-scripts`, `pnpm test`, `pnpm typecheck`, `pnpm e2e:electron` (the built app in real Electron under xvfb), `pnpm e2e` (real export in headless Chromium, plus settings, bin, keys, styles, fonts, layouts, home, guides and touch suites; `e2e/browser.mjs` starts every context with the home screen off, pass `{ home: true }` to test it; run `e2e/make-media.sh` once first; the sandbox Chromium cannot decode H.264).

- Fonts: never commit font files (Supercell's Squad Latin Black is proprietary; the user brings it). Users add fonts in the app; `.gitignore` blocks font extensions. Tests that need the real font read it from `e2e/.media/` (ignored).
- Caption outlines use `src/render/outlinedText.ts`: the outline only grows from the outside of the text, so counters (e, a, g) stay clear. A plain centred stroke fills them with outline colour; do not go back to that.
- Canvas `filter: blur()` ignores the canvas transform (measured). Convert project px to device px with the base transform. `pnpm e2e` has a preview-vs-export check with a tight threshold; keep it tight (a loose one passed the bug).
- Export: container follows the video codec (H.264 -> MP4 + AAC, else WebM + Opus). AAC falls back to `@mediabunny/aac-encoder` when the platform has none (Electron on Linux).
- When adding a test for a bug, run it against the broken code first (negative control).
- CI: `.github/workflows/ci.yml` (checks and e2e) and `build.yml` (APK + Windows + Linux, then a GitHub Release `build-<run>` with every file attached on its own, no zips; only the newest 5 are kept). Artifacts are only the hand-over between jobs. Android uses a fixed public debug keystore (`android/debug.keystore`) so test APKs install over each other. The lockfile must use `git+https://` for turbothemes (the `github:` shorthand records an SSH address that CI cannot clone).
- Touch UI (`src/app/timelineView.ts`): on touch the playhead is fixed in the middle and the timeline scrolls under it (panning = scrubbing). Only the SELECTED clip captures a finger (touch-action none, big handles); unselected clips use pan-x pan-y so they never block panning. `pnpm e2e:touch` drives this with raw CDP touch events. Chromium's `Input.synthesizeScrollGesture` and `synthesizePinchGesture` do not work here; use paced `Input.dispatchTouchEvent`. Pinch-to-zoom works (two fingers, zooms in place so the touched element survives).
- Captions from Whisper pass through `src/transcribe/post.ts` (clamp to the video, drop words on silence, collapse repeat loops). Default language is English (auto-detect on a multilingual model gave nonsense). The audio fed to the model is verified against ffmpeg by `pnpm e2e` (`speechAudio`). The model itself has never been run in the sandbox.
