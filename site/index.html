TurboCut

A light video editor for shorts. Cut on a phone or a PC, with captions generated for you. Nothing is uploaded unless you point it at your own server.

Run it on your own computer

No app to install: a tiny web server that other devices on your network open in a browser.

Releases are named Year.Month.Update, for example 2026.10.3. The app checks for newer ones itself (Settings, Updates).

What it does

  • Multi-track video and audio, with linked sound that cuts and moves with its picture.
  • Built for touch: the playhead stays in the middle, big trim handles, pinch to zoom.
  • Automatic captions, on your device (WebGPU) or on a GPU computer on your network.
  • Caption styles you can edit, share and import, with the font inside the file.
  • Bounce-in captions with clean outlines that keep the holes in letters open.
  • Text layers, and keyframes for position, scale, opacity, volume, blur and pixelate.
  • Media bin, snapping you can switch off, remappable keys, optional waveforms.
  • Exports MP4 (H.264 and AAC) or WebM. Made for shorts under a minute; 16:9 edits up to about twenty minutes work too.

Run your own web server

Want to use TurboCut from any device without installing the desktop app? Download the web bundle above, unzip it, and run (needs Node.js):

node serve.mjs --https

It prints an address such as https://192.168.1.20:8080/. Open that on any device on the same network and accept the certificate warning once. Plain http works on the computer running it, but browsers only allow exporting video on secure pages, so use --https for other devices.
